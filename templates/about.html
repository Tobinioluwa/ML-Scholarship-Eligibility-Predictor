About the Model

How it works

The predictor is a Random Forest classifier trained with scikit-learn on a documented, rule-based synthetic dataset of 6,000 student records (see src/data_generator.py). Features include academic performance, financial need, extracurricular engagement, attendance, and household context. Numeric fields are standardized and categorical fields one-hot encoded inside a single scikit-learn Pipeline, so the exact same transformations used in training are applied to every new prediction.
